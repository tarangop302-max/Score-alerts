# JSR Score Alerts Bot

## Setup
1. `npm install`
2. Discord Developer Portal -> Bot -> enable **Message Content Intent**
3. `npm start`

Keep `DejaVuSans.ttf` and `DejaVuSans-Bold.ttf` either in a `fonts/` folder or next to `index.js`.

## Commands
- `!map` or `!show map`
- `@Bot show map`
- `!mapdebug` - prints the structure of the API response (use it if the map says no data)

Optional settings in index.js: PREFIX, MAP_PATH, ARENA_RADIUS.
